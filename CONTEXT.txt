SUBLIMINAL LEARNING WITH GRADIENT PROJECTION — HANDOFF CONTEXT
================================================================

## What this project is

We're extending the "subliminal learning" result from a recent paper (Section 6.2).
The paper shows that distilling a teacher's AUXILIARY logits (not the class logits)
into a student that shares the same random initialization — using only NOISE inputs —
causes the student to learn to classify MNIST at ~50% accuracy despite never seeing
digits and never training on class logits. This breaks when teacher/student have
different initializations, proving it's about entangled representations in shared
weight geometry, not inherent signal in the aux logits.

## The extension we're building

The user's idea: what if the teacher is only trained on a SUBSET of digits (the
"trait" digits, e.g. {0,1,2,3,4}), and we use gradient projection during
distillation to suppress learning of those trait classes — leaving only the
subliminal knowledge of the UNSEEN classes {5,6,7,8,9}?

The mechanism:
1. Teacher trained on trait digits {0,1,2,3,4} only (cross-entropy, regular logits)
2. Student distilled from teacher's 3 auxiliary logits on noise images (KL divergence)
3. During distillation, compute the gradient direction corresponding to trait
   classification, and PROJECT IT AWAY from the distillation gradient
4. Hypothesis: student should preferentially learn non-trait digits {5,6,7,8,9}

## Architecture (matching paper exactly)

- MLP: (784, 256, 256, 10+m) with m=3 auxiliary logits, ReLU activations
- Outputs: 10 regular logits (softmax for classification) + 3 auxiliary logits
- Teacher trains on regular logits only; aux logits are never in teacher's loss
- Student distills on aux logits only using KL divergence; regular logits evaluated

## Key findings so far (CPU, incomplete runs)

From the first version (which used MSE instead of KL — now fixed):
- Vanilla subliminal distillation from a trait-only teacher showed the student
  learning NON-TRAIT digits preferentially (20.5% non-trait vs 4.6% trait)
- Gradient projection at alpha=1.0 INVERTED this (55.3% trait, 0% non-trait)
- This suggests the distillation gradient is ANTI-CORRELATED with the trait
  classification gradient — fascinating geometric finding
- Negative alpha also didn't simply fix it — the geometry is nonlinear

## Paper reference

The base result is from a paper on "subliminal learning" — Section 6.2 describes
the MNIST MLP experiment. Key details:
- Student (aux only) achieves ~50% test accuracy (100 run average, Fig 10b)
- Cross-model (different init) fails — stays near random
- Student (all logits) achieves ~93%
- This proves subliminal info transfer depends on shared initialization
